```
/character <query>
```

Search characters by name. No AniList account needed. The reply is public.

## Results

Miru shows up to 25 results in a dropdown. Each option shows the character's first appearance and a nickname, so you can tell characters with the same name apart.

The card shows, when known:

- Native (Japanese) name and nicknames
- Age, gender, birthday, height and blood type
- A description
- Anime and manga appearances
- Japanese voice actors (up to 3)
- Favourites count

## Good to know

- Controls last **5 minutes**.
