title: /manga
description: Search manga by title.
---

```
/manga <query>
```

Search manga by title. No AniList account needed. The reply is public.

It works the same way as [`/anime`](/docs/commands/anime/): up to 25 results, with a dropdown to switch between them.

## Results

The card shows:

- Title
- Authors
- Score and rank
- Format
- Chapter and volume counts
- Status and publication dates
- Genres

The footer shows where the data came from (AniList, or MyAnimeList via Jikan) and which result you're on.

## List buttons

If you've [linked AniList](/docs/commands/link/), list buttons appear under the result. For manga, the progress button reads **+1 ch**. See [List buttons](/docs/features/list-buttons/).

## Good to know

- Controls last **5 minutes**.
- Adult titles are excluded from AniList search.
