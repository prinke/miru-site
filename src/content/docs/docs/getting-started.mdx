## 1. Add Miru

You can install Miru in two ways, and you can use both at the same time.

<LinkButton href={INVITE.server} target="_blank" rel="noopener noreferrer">Add to server</LinkButton>{' '}
<LinkButton href={INVITE.personal} target="_blank" rel="noopener noreferrer" variant="secondary">Add to my apps</LinkButton>

| | Server install | Personal install |
| --- | --- | --- |
| Who adds it | A server admin | Any user, for themselves |
| Where commands work | That server (and DMs with the bot) | Any server, DM or group DM you're in |
| Server feed (`/feed`) | Yes | **No**. `/feed` only exists for server installs |
| `/wrapped` server ranking | Yes | Only if Miru is also in that server |
| Permissions | View Channel, Send Messages, Embed Links | None |

**Server install** is for admins who want Miru available to everyone, and for the [server activity feed](/docs/features/server-feed/).
**Personal install** lets you use Miru anywhere, even in servers that haven't added it.

## 2. Try it without an account

These work straight away, no AniList account needed:

- [`/anime`](/docs/commands/anime/), [`/manga`](/docs/commands/manga/) and [`/character`](/docs/commands/character/) to search
- [`/season`](/docs/commands/season/) to browse a season's chart
- [`/trace`](/docs/commands/trace/) and the **What anime is this?** message menu to find a scene from a screenshot
- [`/ping`](/docs/commands/ping/) to check that Miru is online

Everything else needs a linked AniList account.

## 3. Link AniList

Linking lets Miru read your lists and make the changes you ask for, like logging episodes or adding a show to Planning.

<Steps>

1. Run `/link`. Miru replies privately (only you can see it) with instructions and two buttons.

2. Press **Authorize on AniList**, sign in, and approve Miru.

3. AniList shows a code on screen. Copy it.

4. Back in Discord, press **Enter code** and paste the code into the **Authorization code** box.

5. Miru confirms with your AniList name, avatar, anime and manga counts, and the date your access expires.

</Steps>

<Aside type="caution">
Never paste the code into a channel. It's private, and it's what lets Miru act on your account.
</Aside>

You have 5 minutes to press **Enter code**, then 10 minutes to submit it. The code is single-use and expires quickly, so if AniList rejects it, run `/link` again for a fresh one. See [`/link`](/docs/commands/link/) for the details.
