An overview of the public code for contributors. Miru runs on Node.js 18+, discord.js v14 and MongoDB.

<FileTree>

## Commands

Each file in `commands/` exports `data` and `execute`, plus optional `autocomplete` and `components` handlers.

## Buttons that survive restarts

Buttons that have to keep working after a restart, like those on alert DMs, use custom IDs such as `alert_watched:<mediaId>:<episode>`. The prefix routes them to a handler. Other controls use short-lived in-memory collectors.

## Background jobs

- **Alerts** cost about 2 AniList requests per tick no matter how many users there are: one for "what aired" and one for "who's watching it".
- **The feed** reads activity for all members of all servers in one query.
- Both jobs keep a cursor in the `state` collection, so restarts neither repeat nor skip anything.

## Rate limits

AniList allows about 30 requests a minute (down from a published 90). All AniList calls share one limiter.

## Database

MongoDB collections: `users`, `guilds`, `state`, `notifications` (30-day TTL) and `wrapped`.

## Premium module

The public code loads an optional `premium/` module if it exists. It's gitignored and kept private, so the public bot is complete without it.

## Rendering

Wrapped cards are drawn with `@napi-rs/canvas` using the bundled Inter font.
